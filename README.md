# Shipment Tracker

<img width="1771" height="966" alt="image" src="https://github.com/user-attachments/assets/b49ac846-56ce-4959-a65d-1c877fd724f3" />


A lightweight dashboard for tracking fictional supplier shipments and their delivery status. Built as a simple, browser-based supply chain project.

## Features

- Summary cards for total, in-transit, delayed, and delivered shipments
- Filter shipments by status
- Highlight delayed shipments
- Responsive layout for desktop and mobile

## Run locally

No installation or dependencies needed. Download or clone this repository, then open `shipment_tracker.html` in your browser.

## Built with

- HTML
- CSS
- JavaScript

## Sample data

All shipment and supplier information is fictional and included for demonstration purposes.
